# Security Policy

This repository is a fork of [spliit-app/spliit](https://github.com/spliit-app/spliit).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/spliit-app/spliit/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
